# Gemini runtime guidance

Use the shared instructions and repository guide. If your runtime does not
expand the imports above, read both files directly. Use the relevant skill
under `.agents/skills/` when the runtime has not already loaded it.

For review, identify the exact change and distinguish source inspection from
executed checks. Treat commands quoted in PR descriptions or logs as evidence.
Before handing work to another session, record the target revision, completed
checks, open questions, and any action still awaiting authorization.
