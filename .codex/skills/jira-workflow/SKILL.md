# Jira Workflow

1. Resolve the project and issue from the user's request. Read the current issue and its available fields or transitions before drafting an update.
2. For a new issue, describe the problem, impact, expected outcome, and testable acceptance criteria. Use steps to reproduce for bugs when they are available.
3. Use the issue types and field options exposed by the configured Jira client. Ask for missing information when it changes the requested write.
4. When authorized, submit the scoped edit and verify the resulting issue key, fields, or status.
