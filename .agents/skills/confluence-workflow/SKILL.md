# Confluence Workflow

1. Resolve the page by title and space or by page ID. Read its current version and the relevant section before drafting changes.
2. Keep the existing structure, terminology, and unrelated material. Check the meaning of nearby links, tables, or macros before touching them.
3. Use the configured Confluence client when the user requests a write. If the page changes during drafting, reread it and reconcile the intended edit.
4. Read back the resulting section and provide the page link.
