# Handoff Lens

Use this lens for end-of-thread summaries, next-agent handoffs, context
transitions, or cleanup-before-new-thread requests.

## Emphasize

- Start with the user's goal and where the work stands now.
- Name current branches, PRs, worktrees, docs, and local-only files that matter.
- Include validation already run, current CI or GitHub state, blockers, and
  `Pending Verification`.
- Put exact next steps in priority order.
- Point to the most specific skill or roadmap the next agent should read first.

## Suppress

- Raw transcript dumps.
- Speculative next steps that do not materially help.
- Repeating every command when the result is enough.
- Hiding unresolved scope behind confident prose.

## Useful Shape

Make the handoff paste-ready for a fresh agent. Prefer concise bullets over a
narrative recap when several artifacts or branches are involved.
