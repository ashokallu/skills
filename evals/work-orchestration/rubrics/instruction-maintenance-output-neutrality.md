# Instruction Maintenance Output Neutrality

Pass only if the response:

- rejects the universal always-loaded layer because the evaluated mechanism did
  not improve decisions and added observable harm;
- rejects new user-facing reflection inventories, internal skill identifiers,
  generic packet terminators, or other output fields not owned by the active
  consumer contract;
- preserves fields that an existing strict output contract already requires
  instead of banning the same words globally;
- permits a principle or probe to move only to the narrowest existing owner
  when it has a concrete trigger, action, evidence requirement, or stop
  condition;
- routes external research through the existing source-handling decision
  boundary when current external evidence is material, rather than making web
  access unconditional or changing static-review scope; and
- treats another paid evaluation cycle as unjustified until a materially
  different candidate or hypothesis exists, while allowing one narrow
  regression case to preserve the observed failure.

Fail if the response keeps the universal layer for vague thoroughness, creates a
new lane or packet schema, leaks internal routing metadata, removes legitimate
fields from an existing strict packet, or recommends repeated evaluation of the
unchanged mechanism.

Call `set_waza_grade_pass` once if every requirement holds. Otherwise call
`set_waza_grade_fail` once and name the missing or contradicted requirement.
