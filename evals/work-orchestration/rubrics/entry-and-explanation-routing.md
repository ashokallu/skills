# Entry And Explanation Routing

This case is self-contained under the loaded dispatcher; do not require
repository inspection.

Pass only if case A may use fast-exit because one bounded lookup can
establish the narrow fact. Case B must route to the named specialist's
explanation-only path and avoid executing publication. Case C must not
fast-exit and must route the specialist-less multi-file read-only
explanation to zoom-out, with the grounded explanation as the
deliverable rather than a mandatory user-visible system-map ceremony.
It must identify Deterministic Route Precedence as the sole owner of applicable
pre-route gate ordering and must not invent or rely on a second ordering owner.

Call `set_waza_grade_pass` once if every requirement holds. Otherwise call
`set_waza_grade_fail` once and name the missing or contradicted requirement.
