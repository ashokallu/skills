# Database Review Depth Escalation

Pass only if the response returns a separate evidenced
`REVIEW_SCOPE_ESCALATION` to `FULL` for the shared-table migration; keeps
`performance-assessment` as database decision scope and final-packet review
mode; rejects general application architecture or style expansion; stays
static with no shell, query, test, collector, or environment refresh; keeps
scope-control fields outside the Database review packet; preserves independent
database verdict ownership; and does not invoke or substitute the ordinary
reviewer.

Call `set_waza_grade_pass` once if every requirement holds. Otherwise call
`set_waza_grade_fail` once and name the missing or contradicted requirement.
